# Polyvise UI concepts

Generated with the built-in image generation tool. These are visual explorations, not implemented UI. All example arguments, evidence, model labels, metrics and account details are illustrative placeholders.

1. Spectrum Studio: vivid cobalt, coral, chartreuse and lavender; question-first workspace.
2. Afterglow: midnight plum, luminous coral and aqua; focused perspective configuration.
3. Perspective Canvas: teal, apricot, iris and rose; spatial comparison and synthesis.

Recommended direction: Spectrum Studio's visual identity with Perspective Canvas's result organization. Before implementation, keep actual arguments in the post-run state, use supported model and mode settings, and replace all illustrative evidence and confidence metrics with actual run data.
